# 🧢 INFOCOM V1

**Tu estilo. Tu gorra. Tu identidad.**

Primera versión de la tienda web de INFOCOM.

## Incluye

- Página de inicio
- Catálogo de gorras
- Filtros por categoría
- Carrito funcional en frontend
- Diseño responsive
- Sección de marca
- Contacto
- HTML, CSS y JavaScript puro

## Estructura

```text
infocom/
├── css/
│   └── style.css
├── js/
│   └── script.js
├── img/
├── index.html
└── README.md
```

## Ejecutar

Abre `index.html` directamente en el navegador.
